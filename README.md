# ココフォリア 縦横比固定リサイズ (ccfolia-tateyoko)

[ココフォリア](https://ccfolia.com/)のスクリーンパネル・マーカーパネルのサイズを変更するとき、**縦横比を維持したまま**変更できるようにするブラウザ拡張機能です。

> **非公式ツールです。** 本拡張機能は CCFOLIA（ココフォリア）の運営とは一切関係ありません。ご利用の前に必ず [免責事項](#免責事項) をお読みください。

## できること

| 機能 | 内容 |
| --- | --- |
| 設定パネルの数値入力 | 「横幅」を変えると縦幅が、「縦幅」を変えると横幅が、元の比率を保ったまま自動で変わります。 |
| 盤面上のドラッグリサイズ | **Shiftキーを押しながら**リサイズ用のハンドルをドラッグすると、縦横比を保ったままサイズが変わります。 |

例：横幅21・縦幅10のパネルは、横幅をいくつに変えても **21:10** を維持します。

## インストール方法

この拡張機能は Chrome Web Store / Firefox Add-ons では配布していません。ソースを取得して手動で読み込みます。

### 1. ソースを取得

```
git clone https://github.com/<ユーザー名>/ccfolia-aspect-lock.git
```

または、GitHub の「Code」→「Download ZIP」からダウンロードして展開してください。

### 2. ブラウザに読み込む

**Google Chrome / Microsoft Edge など（Chromium系）**

1. `chrome://extensions`（Edgeは `edge://extensions`）を開く
2. 右上（または左下）の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選択する

**Firefox**

1. `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」をクリックし、フォルダ内の `manifest.json` を選択する

> Firefox の一時的なアドオンは、**ブラウザを閉じると削除されます**。毎回の読み込みが手間な場合は、Mozilla によるアドオン署名を行うか、Developer Edition / Nightly 等で署名要件を無効化してください。

## 使い方

### 設定パネルの数値入力

1. 盤面上のスクリーンパネル（またはマーカーパネル）の設定を開きます。
2. 「横幅」または「縦幅」の入力欄をクリック（フォーカス）します。このときの比率が記憶されます。
3. 数値を変更すると、もう一方の値が自動で追従します。

- **Altキーを押している間**は比率固定が無効になり、一時的に自由な値を入力できます。
- 小数を使いたい場合は `content.js` 冒頭の `ROUND_DIGITS` を変更してください（初期値 `0` = 整数に丸める）。

### 盤面上のドラッグ

1. **Shiftキーを押したまま**、パネルの辺または角のハンドルを掴んでドラッグします。
2. 縦横比を保ったままサイズが変わります。
3. 辺のハンドル（横だけ・縦だけが変わるもの）を掴んだ場合も、もう一方の辺が追従します。

- Shiftは**ドラッグを始めるとき**に押している必要があります（途中から押しても有効になりません。途中で離しても、そのドラッグ中は固定が続きます）。
- Shiftを押さずに操作した場合は、通常のココフォリアの挙動のままです。

## 既知の制限

- **グリッドスナップによる丸め**：ココフォリアの盤面は 24px 単位でサイズがスナップされるため、ドラッグ時の縦横比は「グリッド上で最も近い値」に丸められます。比率によっては完全には一致しません（例：15:7 は 15マス単位でのみ厳密に一致）。厳密な比率が必要な場合は、数値入力を使ってください。
- 左辺・上辺のハンドルが存在しないパネル（大きな画像など）では、右辺・下辺・右下角のみ対応します。
- 数値入力の比率固定は、`name="width"` と `name="height"` の組を持つ入力欄すべてに作用します。スクリーン・マーカーパネル以外の同名の入力欄にも効く可能性があります。
- ココフォリア側の仕様変更（DOM構造、使用ライブラリ、クラス名など）により、予告なく動作しなくなる可能性があります。

## 技術情報

### ファイル構成

```
ccfolia-aspect-lock/
├─ manifest.json   # Manifest V3（Chrome / Firefox 共用）
├─ content.js      # 設定パネルの数値入力の比率固定
└─ drag.js         # 盤面上のShift+ドラッグの比率固定
```

どちらも `https://ccfolia.com/*` に注入されるコンテンツスクリプトで、権限（`permissions`）は要求しません。外部への通信やデータの保存は行いません（`storage` 等も使用していません）。

### content.js：数値入力の比率固定

- **対象の特定**：ココフォリアは MUI（Material-UI）を使用しておりクラス名がハッシュ化されているため、クラス名には依存せず、`input[type="number"][name="width"|"height"]` で入力欄を特定します。
- **イベント委譲**：`document` に対して `focusin` / `input` を**キャプチャ段階**で登録しているため、設定パネルが後から描画（再描画）されても動作します。
- **比率の記録**：入力欄へのフォーカス時に `width / height` を記録します。ただし、直前に記録した比率と矛盾しない（丸めた結果が現在値と一致する）場合は、記録済みの比率を維持します。これにより、整数への丸めによる誤差が繰り返しの操作で蓄積するのを防ぎます。
- **React 管理下の値の書き換え**：React の制御コンポーネントは `input.value = ...` の直接代入を検知できないため、`HTMLInputElement.prototype` の `value` のネイティブ setter を呼び出したうえで、`input` イベントを `bubbles: true` で発火させています。
- **無限ループ防止**：拡張機能が発火させたイベントは `isTrusted === false` になるため、`isTrusted` が `true` のイベント（ユーザー操作）のみを処理します。
- **無効なケース**：空欄・0・負数の入力、および Alt キー押下中は何もしません。

### drag.js：Shift+ドラッグの比率固定

盤面上のリサイズハンドルは、DOM構造（`cursor: se-resize` 等のスタイルを持つ絶対配置の `div` 群、`user-select: none`）から [re-resizable](https://github.com/bokuweb/re-resizable) 系のライブラリであると推測しています（推測であり、確認はしていません）。ライブラリのプロパティ（`lockAspectRatio` 等）を外部から変更することはできないため、**マウスイベントの座標を補正する**方式を採用しています。

1. **`mousedown`（キャプチャ段階）**
   Shift 押下中にリサイズハンドルが押されたことを検知します。リサイズ対象の要素（`.movable`）の `style.width / height` から元の比率を求め、ハンドルの `cursor` 値と `style.right / bottom` から、どの方向のハンドルかを判定します。
2. **辺ハンドルの差し替え**
   辺ハンドル（`col-resize` / `row-resize`）は、ライブラリ側で一方の辺しか変更されません。そこで、元のイベントを `stopImmediatePropagation()` で止め、同じ親要素内の角ハンドル（`se-resize` など）に対して合成した `mousedown` を発火させ、角ハンドルを掴んだ状態にします。
3. **`mousemove`（`window` のキャプチャ段階）**
   ドラッグ中の実マウス座標から、「比率を維持した場合の新しい幅・高さ」を計算します。角ハンドルでは、元のサイズからの変化率が大きい軸を基準にします。辺ハンドルでは、掴んだ辺の軸を基準にします。これを元に補正後の座標を求め、元のイベントを `stopImmediatePropagation()` で止めたうえで、補正後の座標を持つ `MouseEvent` を `window` に再発火させます。
4. **再入防止**
   再発火中は `dispatching` フラグを立て、さらに `isTrusted` もチェックして、自分が発火したイベントを再処理しないようにしています。
5. **終了**
   `mouseup`（キャプチャ段階）と `blur` でセッションを破棄します。

この方式の利点は、**サイズの計算・グリッドスナップ・保存は全てココフォリア本体（ライブラリ）が行う**ため、画面の表示と保存される値が食い違わないことです。一方、ライブラリが `mousemove` 以外（`pointer` イベントなど）に切り替わった場合は動作しなくなります。

### 設定値

| 場所 | 定数 | 初期値 | 説明 |
| --- | --- | --- | --- |
| `content.js` | `ROUND_DIGITS` | `0` | 自動計算される値の小数桁数（0で整数に丸める） |
| `drag.js` | `GRID` | `24` | 盤面のスナップ幅。比率の丸め誤差を許容判定する目的でのみ使用 |
